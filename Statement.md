## Student Performance Management System
----------------
## Problem statement 
Manual management of students' academic data is very time-consuming and susceptible to errors.
Teachers or administrators can find difficulty in:
Record keeping for several students
Calculating class average quickly
Identifying which students pass or fail
Generating consistent performance reports
There is a requirement for a simple automated system to store information about the students, process marks, and generate a neat, formatted performance report.

## Scope of the project 
This project targets the development of a simple terminal-based student management and reporting system with Python.
The system allows:
Storing Student Names and Marks
Calculating overall class statistics
Automatic analysis of student performance with pass/fail criteria
Displaying organized output reports
The scope includes data management, processing, and reporting, but does not include:
Database storage
Graphical user interface
Advanced analytics
These can be added in future versions.

## Target user 
This system is designed for:
1. Teachers
In order to easily maintain class data and generate reports.
2. School/College Administrators
To monitor performance and keep digital records.
3. Students (for self-learning)
To comprehend programming ideas such as functions, modules, and data manipulation.
4. Beginner Python Learners
For a simple modular programming example.
