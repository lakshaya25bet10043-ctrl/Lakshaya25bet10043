# The Student Performance Management System 
----------------------

## overview
The Student Performance Management System is a Python-based modular project to maintain student information, calculate class performance, and generate reports.
The system allows users to:
Add students with their marks
View all student information
Process the data by calculating class average.
Generate a final report that shows pass/fail status
This is a beginner-friendly project that showcases modular programming, data structures, and basic automation using Python.

-----------------------------
## features
Add new students with marks
1. Store student data in a list

2.List all students

3.Calculate class average

4.Produce a performance report

5.Clear pass/fail indicators

6.Modular structure (3 separate modules + main file)
----------------------------
## Technologies / tools used
Python 3
VS Code / PyCharm / Notepad++
Functions, Lists, Dictionaries, Modular Programming
GitHub for version control


## Steps to install and run the project 
1. Install Python
Download & install Python 3.10+
Check version:
python --version

2. Create New Folder
mkdir StudentProject
cd StudentProject

3. Create the 4 Python Files
user_management.py
data_processing.py
reporting.py
main.py
Copy your code into them.
-------------------------------------
## Instructions for testing
